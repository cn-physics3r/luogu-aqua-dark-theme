# Luogu Aqua Dark

一个通过 Stylus 加载的洛谷暗色用户样式，采用近黑/深灰表面、低饱和边框和冷蓝青色交互强调。当前版本为 `0.1.65`，唯一的主代码与可分发文件是 `luogu-aqua-dark.user.css`。

## 安装

1. 安装浏览器扩展 [Stylus](https://add0n.com/stylus.html)。
2. 打开 `luogu-aqua-dark.user.css`，复制全部内容。
3. 在 Stylus 中新建样式，粘贴并保存。
4. 访问 [洛谷](https://www.luogu.com.cn/)，确认样式已启用。

也可以直接打开 [Raw UserStyle](https://raw.githubusercontent.com/cn-physics3r/luogu-aqua-dark-theme/main/luogu-aqua-dark.user.css) 交给 Stylus 安装；样式元数据包含主页、问题反馈和更新地址。

`0.1.55` 将 `@namespace` 迁移到当前仓库地址。若旧版本是通过 URL 安装，Stylus 可能将新版本识别为另一份样式；确认新版本生效后，应停用或删除旧副本，避免重复注入。

## 当前覆盖

- 主站基础：仅匹配 `www.luogu.com.cn`，覆盖页面背景、链接、选中文本、滚动条和键盘焦点状态。
- 导航与外壳：旧版顶栏、现代导航、顶部栏、左右侧栏、应用背景、应用菜单和页脚。
- 内容组件：文章、卡片、面板、评论、标签页、选择器、弹窗、气泡提示、表格、代码块和引用块。
- 表单与操作：输入框、文本域、下拉列表、复选项、普通按钮，以及成功和危险操作状态。
- 题目与比赛：题目列表、题目详情、筛选器、难度与算法标签、比赛列表、比赛类型徽章和分页栏。
- 提交与评测：IDE 编辑器、语法高亮、行号、活动行、选区、提交按钮、评测记录、状态标签和详情字段。
- 个人中心：个人资料导航、统计字段、资料卡片和做题趋势热力图；活动格使用与右侧图例一致的蓝青题数强度梯度。
- 首页与题单：动态切换、运势与日历信息、Highcharts 图表、题单分类卡片、导航和进度圆环。
- 语义状态：保留成功、警告、错误、难度和比赛类别的差异，并调整为适合深色背景的低饱和配色。
- 图片资源：赛事图片、头像、轮播图和视频保持原样，不施加暗色滤镜。

## 设计边界

- 项目保持纯 CSS，不引入 JavaScript、外部字体、外部图片资源、构建工具或运行时依赖。
- 不改变洛谷的信息架构和主要布局，只调整表面、文字、边框、阴影和交互状态。
- 不向洛谷网校等其他子域注入主题。
- 不对赛事图片、头像、轮播图、视频和其他媒体施加暗色滤镜。
- 普通链接、导航、表单控件和按钮保留可辨识的悬停、聚焦、选中和禁用状态。
- 红、绿、蓝、橙、黄、紫等语义类别保持可区分，但避免形成刺眼的高亮色块。

## 更新本地样式

本地 CSS 文件不会自动同步到 Stylus。修改或下载新版本后，需要将 `luogu-aqua-dark.user.css` 的完整内容重新粘贴到 Stylus、保存样式并刷新洛谷页面。
