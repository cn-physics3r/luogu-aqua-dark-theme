# Luogu Aqua Dark

一个通过 Stylus 加载的洛谷暗色用户样式，采用近黑/深灰表面、低饱和边框和冷蓝青色交互强调。当前版本为 `0.1.15`，唯一的主代码与可分发文件是 `luogu-aqua-dark.user.css`。

## 安装

1. 安装浏览器扩展 [Stylus](https://add0n.com/stylus.html)。
2. 打开 `luogu-aqua-dark.user.css`，复制全部内容。
3. 在 Stylus 中新建样式，粘贴并保存。
4. 访问 [洛谷](https://www.luogu.com.cn/)，确认样式已启用。

## 当前覆盖

- 主站作用域：仅匹配 `www.luogu.com.cn`。
- 主题基础：通过 `--lct-*` 变量统一管理画布、表面、边框、文字、控件、代码块、阴影和状态色，并同步覆盖洛谷的 `--lfe-color--*` 与 `--lcolor--*` 颜色令牌。
- 页面基础：页面背景、链接、选中文本和滚动条；保留页面原有信息架构和主要布局。
- 页脚横幅：站点底部页脚使用深色表面、边框和次级文字，避免保留浅色主题背景。
- 导航与外壳：旧版顶栏、现代导航、顶部栏、左右侧栏、应用背景以及应用弹出菜单。
- 卡片与面板：文章、面板、评论、现代卡片、标签页、下拉菜单、选择器、弹窗、气泡提示和题目卡片的表面、边框、层级与文字。
- 题目页头部统计：提交数、通过数、时间限制和内存限制使用适合深色题目卡片的文字层级。
- 个人中心：个人资料导航、统计数字、页面背景和做题趋势图的文字使用适合深色卡片的层级。
- 表单与按钮：输入框、文本域、下拉框、占位符、焦点环、普通按钮和成功/危险按钮。
- 表格与代码：表格、表头、单元格、代码块、`pre`、`code` 和引用块。
- 题目列表：筛选控件、结果统计、列表表头与分隔线、题目标签、难度徽章、通过率进度条和固定分页栏统一为暗色层级，同时保留分类语义差异。
- 题目提交页 IDE 模式：以 `.ide-container` 和包含 `.cm-editor` 的编辑面板为作用域，覆盖提交代码/文件标签、语言选择器、语言菜单、O2 选项、CodeMirror 编辑器、语法高亮、深色行号栏、活动行、选区、提示文字和提交按钮。当前 C++ 模式的 CodeMirror 6 使用动态 `ͼ*` token 类进行语义着色。
- 旧版评论：评论背景、边框、评论气泡尖角、评论元信息。
- 语义状态：`am-panel-*` 面板、`lg-fg-*` 文字色、`lg-bg-*` 标签背景，以及首页等页面使用的 Highcharts 文字、网格线和坐标轴。
- 首页可读性特例：运势卡片中的小吉/宜使用主题红，日历计数使用深色主题成功色，Highcharts tooltip 使用深色提升表面、主文字和边框，避免原始亮色内联样式在暗色背景上失去对比度。
- 图片资源：对 `img` 和 `video` 明确取消滤镜，不对赛事图片、头像、轮播图等资源做暗色滤镜处理。

当前版本主要提供跨页面的基础主题和通用组件覆盖，不预先猜写未经浏览器确认的题解、评测记录或个人主页专属类名。需要扩展这些页面时，应先核实实际 DOM。

IDE 模式的选择器已在真实洛谷题目页中核对；如果洛谷更新编辑器组件，应重新检查 `.cm-editor`、`.cm-gutters`、`.cm-lineNumbers` 和实际 token 类名。

## 文件结构与维护顺序

项目保持单个可直接复制到 Stylus 的 CSS 文件，不引入 JavaScript、构建工具、运行时依赖或外部资源。样式文件按以下顺序组织：

1. UserStyle 元数据和 `www.luogu.com.cn` 主站作用域。
2. `--lct-*` 主题令牌，以及洛谷十六进制和 RGB 颜色令牌映射。
3. 页面基础样式、链接、选区和滚动条。
4. 导航和页面外壳。
5. 卡片、面板、菜单、弹窗和通用文字。
6. 表单、按钮、表格、代码块和旧版评论。
7. 语义状态、标签和 Highcharts 覆盖。

新增规则应优先放在对应的页面或组件区块中；只有确认会跨页面复用时，才放入通用组件区块。原生 `input`、`button`、`table` 和 `pre` 规则应限制在已知的洛谷应用根节点内，避免影响站点外层结构。

## 设计约束

- 仅匹配 `www.luogu.com.cn` 主站，不向洛谷网校等其他子域注入主题。
- 纯 CSS，无 JavaScript、外部字体、外部图片资源或构建步骤。
- 不改变页面信息架构和主要布局，只调整表面颜色、层级、边框、阴影和交互状态。
- 不对赛事图片、头像、轮播图和其他媒体施加暗色滤镜；图片与视频规则保持 `filter: none`。
- 颜色、阴影和状态色优先使用 `:root` 中的 `--lct-*` 变量，避免在页面规则中重复硬编码颜色。
- 题目列表中用于识别洛谷内联样式的 `rgb(...)` 属性选择器保留字面值；它们只用于匹配 DOM，不是主题颜色声明。
- 普通链接和导航链接取消继承原站颜色过渡，避免暗色主题下出现先跳变再渐变的颜色切换。
- 题库切换栏保留选中背景并使用深色文字提高对比度；题目列表表头与所在卡片保持同色，结果统计数字使用主题正文色。
- 语义状态保留红、绿、蓝、橙、黄、紫等类别差异，但使用低饱和透明底色和柔和边框，避免形成高亮色块。
- 新增选择器前必须先在浏览器中确认实际 DOM；`!important` 只用于确实需要压过洛谷原样式的视觉属性。

## 手动验证清单

每次修改后，在 Stylus 中至少检查：

- 首页登录态：顶栏、现代导航、左右侧栏、应用菜单、卡片、评论、轮播图和 Highcharts 图表。
- 题目列表与题目页：筛选器、搜索框、按钮、卡片、表格、题面、代码块、标签和分隔线。
- 题目页 IDE 模式：语言选择器和下拉菜单、O2 选项、编辑器背景、代码 token、行号栏、活动行、选区、输入/输出工具栏和提交按钮。
- 评测记录页：筛选控件、记录表格、状态标签、详情文字和分页按钮。
- 移动端宽度：基础卡片、表单、代码块和页面横向溢出情况。
- 图片资源：赛事图片、头像、轮播图及视频不应被暗色滤镜处理。

本地 CSS 文件不会自动同步到 Stylus。修改后需要将 `luogu-aqua-dark.user.css` 的完整内容重新粘贴到 Stylus、保存样式并刷新洛谷页面，再进行视觉核对。
